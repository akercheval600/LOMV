# LOMV
Simulation code for long-only minimum variance portfolio studies, supporting Section 3 of Kercheval and Ololade, "The long-only minimum variance portfolio in a one-factor market: theory and asymptotics".

Three self-contained python programs are included:
lomv_active_ratio_sim.py
nonconverngence_example.py
weights_vs_beta.py

Figure 1.1 of the paper is produced by weights_vs_beta.py,  Figure 3.1 and Table 3.1 are produced by lomv_active_ratio_sim.py. Figure 3.2 is produced by nonconvergence_example.py.
All three programs are documented and can be run directly with a modern python compiler.
