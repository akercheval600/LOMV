# LOMV
Simulation code for long-only minimum variance portfolio studies, supporting Section 3 of Kercheval and Ololade, "The long-only minimum variance portfolio in a one-factor market: theory and asymptotics.

Three self-contained python programs are included:
active_ratio_2.py
nonconverngence_example_clean2.py
weights_vs_beta.py

Figure 1 of the paper is produced by weights_vs_beta.py,  Figures 2 and 3 are produced by active_ratio_2.py. Figure 4 is produced by nonconvergence_example_clean2.py.
All three programs are well-documented and can be run directly with a modern python compiler.
